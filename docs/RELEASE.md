# Msgzle 0.0.2 - developer preview

Native General and Advanced Settings replace the browser setup on Mac. This release adds a status menu, local privacy-safe logs, local Contacts suggestions and manual recipients, explicit Selected/Everyone policy, user-selected login and notification settings, API key reveal/copy, rate spacing and safe pre-dispatch checks. The user-supplied rocket artwork is the app icon. Receive/history are still disabled.

Choose Msgzle-x64.dmg for Intel or Msgzle-arm64.dmg for Apple Silicon. Drag Msgzle to Applications. No startup item is installed automatically. Release version is stamped from its git tag before signing; development builds display a build number. Developer ID signing, Apple notarization/stapling, strict signature and Gatekeeper checks gate release artifacts. SHA-256 files accompany DMG and ZIP.

Sending defaults off. Everyone is an explicit choice and does not bypass sending disabled. Dispatch accepted means submitted to Messages, not recipient delivery; uncertain sends are never blindly retried. Pre-dispatch retries only check whether Messages is running. A private Intel/macOS 26.7.1 build passed an owner-reviewed real text-send test. The owner confirmed the first-click Settings fix works. Full General/Advanced visual review remains unverified. ARM runtime, older macOS compatibility, a clean-install permission flow and an end-to-end Sparkle upgrade have not been proven.

Contacts permission is optional and local. The app does not request Full Disk Access for its text-only send path. Sparkle archives are signed and verified against the embedded public key. Per-architecture feeds are published only after corresponding release assets are public. This is an early developer preview, not production-ready. macOS13 is the compilation target, not a verified support promise; upstream Photon v3 history features require macOS26.
